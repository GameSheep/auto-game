# 掉落物名词表（字条模板）

这里每个图片文件 = 一个物品名。**文件名就是物品名**，`vision.nametags.enabled: true` 后
由 `autogame/vision/nametags.py` 装载。

```
强化石.png                    → 词条「强化石」
强化石__2.png                 → 同一物品的第二张样本（`__N` 后缀不算名字的一部分）
传说·破城斧.png               → 词条「传说·破城斧」
```

## 怎么裁

1. 游戏里让这个物品的**名字出现在光柱上方**，截一张图。
2. 裁的时候**只裁字**，左右各留 2~4px、上下留 1~2px，不要带背景大块、不要带边框图标。
   - 带一块纯色背景不会更稳：装载时会算灰度方差，方差过低的直接拒收
     （`q_letter.png` 的老毛病：一张没笔画的图对每帧都给 0.88）。
3. 存 PNG（JPEG 的压缩噪点会拉低分数）。

## 阈值怎么定

默认 `threshold: 0.72`。判断标准不是"越高越安全"，而是：

- 拿 20~30 张真实截图跑一遍，看**同名词条的最低分**和**最容易混的另一个词条的最高分**；
- 阈值取两者中间。两个分布重叠 → 说明这两个名字裁得太像，补一张样本或换裁法。

## 三件它做不到的事（不是 bug）

1. **新物品必须补字条**。没有字条就认不出来，认不出来时**不猜**（返回 None）。
   配了 `whitelist` 的话，认不出 = 不捡 —— 这是刻意的。
2. **字体缩放变了要重裁**，或者往 `scales` 里加一档（`[1.0, 0.85]`）多匹配一次。
3. **同色同形不同名**（比如只差一个字）容易混。这种情况建议只把"必须捡的那个"放进
   词表，其余不理 —— 词表是白名单，不是字典。
